# Compliance Report

版本：1.1


## Purpose

统一规范检查输出格式。


## Status

检查状态：

PASS
全部符合规范，无需处理。


WARNING
存在问题，但不会阻止继续开发。


FAIL
存在严重规范错误，需要修复后继续。


## Check Mark


通过：


[✓]



警告：


[!]



失败：


[✗]



## Format


状态：

PASS / WARNING / FAIL


检查项目：

示例：


状态：

WARNING


检查项目：

[✓] 文件命名

[!] Scene结构存在优化建议

[✗] 核心目录结构违反项目规范


问题：

描述发现的问题。


建议：

提供解决方案。


遗留：

记录未解决事项。
