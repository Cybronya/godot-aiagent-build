# Metadata

每个资源分成两类信息。

## Auto

Scanner 管理：

- path
- filename
- extension
- size_bytes
- modified_at
- sha256
- width
- height
- path_hints
- filename_hints

## Human

人确认：

- id
- type
- category
- tags
- status
- subtype
- character
- action
- direction
- frame
- description
- source
- notes

Auto 是事实；Human 是语义。
