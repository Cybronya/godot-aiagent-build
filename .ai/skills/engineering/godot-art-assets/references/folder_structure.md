# Folder Structure

## Standard top-level folders

```text
assets/
├── characters/
├── environments/
├── tilesets/
├── backgrounds/
├── props/
├── items/
├── vfx/
├── ui/
├── portraits/
└── fonts/
```

## Guidelines

- 顶层目录表达资源大类。
- 子目录表达稳定主题、对象或用途。
- 避免无意义的深层目录。
- 不使用 `new`、`old`、`final` 作为长期目录。
- 不因一次性任务创建临时永久目录。
