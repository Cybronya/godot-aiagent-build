# Architecture Memory Retrieval

## Search Order

1. Architecture index
2. Relevant Architecture Decisions
3. Relevant validated Patterns
4. Architecture overview
5. Current project structure and source code

## Search Concepts

Use Feature, Module, System, Ownership, Dependency, Autoload, Data Ownership, Lifecycle and Communication Boundary.

## Reuse

Accepted Decision: active constraint unless the user explicitly requests an architecture change.

Validated Pattern: default starting structure, adapted to context.

Conflicts: identify conflicting decisions and resolve according to decision priority. Never silently choose.
